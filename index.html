Altspace & Banter game

Mancala

A synced multiplayer Mancala (Kalah) board. Made for SideQuest / AltspaceVR worlds, and it also works in Banter.

There is no server: players stay in sync through the space's shared state, and the game is plain static files served from mancala.firer.at.

2a. Add it in Unity

You need a Unity project with the Altspace / Banter Creator SDK already set up, and your world's scene open.

  1. Make an empty object. In the top menu choose GameObject › Create Empty. Rename it to Mancala so you can find it later (the object's name doesn't matter, only the slug does).
  2. Put it at the middle of the world. With the new object selected, look at Transform in the Inspector and set Position to 0 0 0 and Rotation to 0 0 0. Why: you don't move the game by moving this object. You move it with the snippet's own position and rotation settings (step 6). If the object (or anything it's inside) isn't at 0 0 0, the SDK's gizmos won't line up with where it really appears.
  3. Add the Snippet component. Click Add Component, type Snippet in the search box, and pick BS › Snippet.
  4. Type the slug and press Enter. In the Snippet's Slug box type and press Enter (the box only takes it after Enter or clicking somewhere else). It downloads the snippet and adds it to your world's Assets/WebRoot/index.html for you. After a moment the Inspector shows the title Mancala and a list of settings. If nothing happens, click Refresh from server.
  5. Save the scene. Press Ctrl + S (Windows / Linux) or Cmd + S (Mac). Do this every time you add or remove a snippet. Closing Unity without saving is the main way extra copies of the snippet end up in index.html.
  6. Place and configure it. Change the settings in the Inspector, or drag the gizmo handle in the Scene view to move it. All settings are listed on GitHub.
  7. Upload your world the same way you always do, then join it in Altspace to play.

Multiple copies in one world: you can add more than one Mancala snippet. In Unity each placement automatically gets its own separate game state unless you set the same room name on both.

2b. Add it on the website

  1. Open your world for editing on altvr.app and go to the Snippets section.
  2. Find Mancala. Set the list to show All snippets, then search for Mancala (or scroll to it) and open it.
  3. Copy it. Click Copy & open index.html. This copies the snippet's code and opens your world's HTML (or copy the full snippet code below).
  4. Paste it in the right place. If your HTML has these two lines, paste between them: 
    <!-- snippet section -->
   paste here
<!-- end snippet section -->
    If it doesn't have them, paste it just before </body>.
  5. Change the settings by editing the values in quotes in the pasted code, for example position="0 1 2". If you paste more than one copy, give each one its own room (like room="table-1" and room="table-2") so they stay separate.
  6. Save, then join your world to play.

Keep the code tidy. Every value needs quotes around it (sound-volume="0.4", not sound-volume=0.4), and a & in any link must be written as &amp;. Unity reads this part strictly, and one mistake can break the whole snippet section.

The full snippet code

This is everything the snippet adds, with every setting at its default. Click the code to copy it.

Full snippet code
<!-- snippet section -->
<bs-snippet name="mancala" title="Mancala"
  description="Synced multiplayer Mancala board with seat locking."
  script="https://mancala.firer.at/snippet.js"
  room=""
  position="0 1 2"
  rotation="0 0 0"
  scale="0.5"
  lit="true"
  add-lights="false"
  turn-cooldown="5"
  lock-timeout="90"
  cull-distance="20"
  sound-volume="0.4"
  sound-near="2.5"
  sound-far="10"
  hide-ui="false"
  hide-board="false">
  <bs-gizmo type="position" attribute="position"/>
  <bs-gizmo type="box" attribute="position" size="2.15 0.1 0.68"/>
</bs-snippet>
<!-- end snippet section -->

2c. Banter (or manual): add it with a script tag

Paste this into a Banter space's HTML, or into an Altspace world's Assets/WebRoot/index.html (outside the snippet section). Give each copy its own instance to have more than one game in a space.

Script tag
<script src="https://mancala.firer.at/Mancala.js" position="0 1.1 -2" lighting="lit"></script>

All the settings are listed on GitHub.

Features

  • Standard Kalah rules, with captures and extra turns
  • A turn panel with seats, Reset and Mute
  • Seat locking
  • Switches itself off when you are far away
  • Several independent boards in one world

How to play

Two players, 6 pits each plus a store, 4 stones per pit.

  1. Click one of your pits to pick up its stones and sow them one per pit, counter-clockwise, skipping your opponent's store.
  2. Last stone in your store: take another turn.
  3. Last stone in an empty pit on your side: capture it and the stones in the opposite pit.
  4. The game ends when one side is empty. Most stones wins.
